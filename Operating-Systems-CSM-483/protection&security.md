# Protection and Security

**Protection** is a mechanism for controlling access by processes or users to resources defined by the operating system.

**Security** is the defense of a system against internal and external attacks. Security threats include:

- Denial-of-service attacks
- Worms
- Viruses
- Identity theft
- Theft of service

Systems generally first distinguish among users to determine who can do what.

## User Identification

- **User identities**, such as user IDs or security IDs, include a user’s name and an associated unique number.
- The user ID is associated with all files and processes belonging to that user to determine access control.
- A **group identifier** (group ID) allows a set of users to be defined and managed together. It is also associated with each process and file.
- **Privilege escalation** allows a user to change to an effective ID with more rights.

# Virtualization

Virtualization allows operating systems to run applications within other operating systems. It is a vast and growing industry.

## Emulation

**Emulation** is used when the source CPU type is different from the target CPU type, such as running PowerPC software on an Intel x86 system.

- Emulation is generally the slowest method.
- When a computer language is not compiled to native code, **interpretation** is used.

## Virtualization

In virtualization, an operating system natively compiled for a CPU runs guest operating systems that are also natively compiled.

- For example, VMware can run Windows XP guests, each running applications, all on a native Windows XP host operating system.
- A **Virtual Machine Manager (VMM)** provides virtualization services.

# Virtualization on Laptops and Desktops

A VMM allows a user to install multiple operating systems and run applications written for operating systems other than the native host.

Examples and uses include:

- An Apple laptop running macOS as the host and Windows as a guest operating system
- Developing applications for multiple operating systems without needing multiple physical systems
- Testing applications without needing multiple physical systems
- Executing and managing computing environments within data centers

# Computing Environments: Traditional

Traditional computing environments consist of stand-alone, general-purpose machines.

However, this distinction has become blurred because most systems are interconnected with other systems, such as through the Internet.

- **Portals** provide web access to internal systems.
- **Network computers**, or thin clients, are similar to web terminals.
- **Mobile computers** interconnect through wireless networks.
- Networking is becoming ubiquitous; even home systems use firewalls to protect computers from Internet attacks.

# Computing Environments: Mobile

Mobile computing environments include handheld smartphones, tablets, and similar devices.

## Mobile Devices

Mobile devices differ from traditional laptops in several ways:

- They include additional operating-system features, such as GPS, used by applications such as Waze.
- They enable new types of applications, such as augmented reality.
- They use IEEE 802.11 wireless networks or cellular data networks for connectivity.
- The leading mobile operating systems are Apple iOS and Google Android.

# Computing Environments: Distributed

A **distributed system** is a collection of separate, possibly heterogeneous, systems connected through a network.

A network is a communications path. The most common network protocol is TCP/IP.

Common types of networks include:

- Local Area Network (LAN)
- Wide Area Network (WAN)
- Metropolitan Area Network (MAN)
- Personal Area Network (PAN)

A **network operating system** provides features that allow systems to share data across a network.

- A communication scheme allows systems to exchange messages.
- It creates the illusion of a single system.

# Computing Environments: Client-Server

Dumb terminals have been replaced by smart personal computers.

Many systems now act as servers, responding to requests generated by clients.

- A **compute-server system** provides an interface for clients to request services, such as database services.
- A **file-server system** provides an interface for clients to store and retrieve files.

# Computing Environments: Peer-to-Peer

A **peer-to-peer (P2P)** system is another model of a distributed system.

Unlike the client-server model, P2P does not distinguish between clients and servers.

- All nodes are considered peers.
- Each node may act as a client, a server, or both.
- A node must join the P2P network before it can participate.

## Joining a P2P Network

A node can join a P2P network by:

- Registering its service with a central lookup service on the network
- Broadcasting a request for a service and responding to requests for services through a discovery protocol

Examples of P2P systems include Napster, Gnutella, and Voice over IP (VoIP) applications such as Skype.

# Computing Environments: Cloud Computing

**Cloud computing** delivers computing, storage, and even applications as a service across a network.

It is a logical extension of virtualization because it uses virtualization as the basis for its functionality.

- For example, Amazon EC2 provides thousands of servers, millions of virtual machines, and petabytes of storage available over the Internet.
- Users pay based on usage.

## Types of Cloud Computing

| Type | Description |
|---|---|
| **Public cloud** | Available over the Internet to anyone willing to pay |
| **Private cloud** | Run by a company for its own use |
| **Hybrid cloud** | Includes both public and private cloud components |
| **Software as a Service (SaaS)** | One or more applications available over the Internet, such as a word processor |
| **Platform as a Service (PaaS)** | A software stack ready for application use over the Internet, such as a database server |
| **Infrastructure as a Service (IaaS)** | Servers or storage available over the Internet, such as storage for backup |

## Cloud Computing Components

Cloud computing environments are composed of:

- Traditional operating systems
- Virtual Machine Managers (VMMs)
- Cloud management tools

Internet connectivity requires security measures such as firewalls.

**Load balancers** distribute traffic across multiple applications.

# Computing Environments: Real-Time Systems

Real-time embedded systems are the most prevalent form of computers.

They vary considerably and may use special-purpose operating systems, limited-purpose operating systems, or real-time operating systems.

- Their use is expanding.
- Many other special computing environments exist as well.
- Some have operating systems, while others perform tasks without an operating system.

A **real-time operating system** has well-defined, fixed time constraints.

- Processing must be completed within the required constraint.
- Correct operation is achieved only if the constraints are met.

# Open-Source Operating Systems

**Open-source operating systems** are made available in source-code format rather than only as closed-source binary files.

They are often associated with opposition to copy protection and Digital Rights Management (DRM).

## Open-Source Movement

- The movement was started by the Free Software Foundation (FSF).
- The FSF uses the “copyleft” GNU Public License (GPL).
- Examples include GNU/Linux and BSD UNIX, including the core of macOS.

## Virtualization Tools

Open-source operating systems can be run using virtual machine managers such as:

- VMware Player, which is free on Windows
- VirtualBox, which is open source and free on many platforms

These tools can be used to run guest operating systems for exploration and learning.
